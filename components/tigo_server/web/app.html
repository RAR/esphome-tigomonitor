Tile color compares each panel to its string median — answers "is this panel keeping up with neighbors right now?". Low output at dawn, dusk, or under cloud cover is expected and shifts the median, not the color. The small stripe at the bottom of a tile compares to the per-panel nameplate rating (when set) using the same green/yellow/red bands — useful for spotting cases where the whole string is below rating but individual panels still look "on par" with each other.

    RS485 adapter
    —

    Nothing is opened until you choose the adapter here, so other serial devices on this machine, such as a Zigbee stick, are left alone. Listing the ports does not open them.

    Serial portThe RS485 adapter on the Tigo bus
    Bus roleListen beside the CCA; run the bus in its place with the CCA unplugged; or stand by, beside a CCA or another master, and take the bus over if it stops (experimental)
    Take over afterSeconds with no master heard before this one runs the bus. Of two standbys, give the one you prefer the shorter time. The default 3 s suits two monitors; beside a working CCA use 30 s or more, since a CCA that reboots is quiet for longer than that and never gives the bus back. Losing power on one master no longer stops the array: the other takes over, so rapid shutdown must cut the TAP's own power
    Bring up the TAPIf the gateway is found at its factory address (after a power cut), re-address it and start it. Needs the real CCA on hand to recover a stranded gateway (experimental)
    Send the CCA's housekeepingSend the CCA's 0x41 to each optimizer in turn, its hourly 0x0B00 and 0x22, and its reads of the TAP's node table (experimental)
    Query the optimizersAsk each optimizer the CCA's five questions (version, tests, info, smart, MPPT), again until it answers (experimental)
    Let queries change optimizer settingsSend the CCA's two writes when an optimizer's answer calls for them: #00w255 after an Info reading 00, and Smrt mode S after one in mode N. Needs Query the optimizers (experimental)
    Open discovery only when neededAs the CCA does: keep the TAP's join window open only while an optimizer in a string hasn't reported today, in daylight. With none in a string, it stays open as now. The Bus page's Disable still wins (experimental)
    Let me change the TAP's tableAllow the Devices page to add an optimizer to the TAP's list, or remove one, as the CCA does. Removing erases the whole table and writes the rest back. Dry runs work with this off (experimental)
    Read the TAP's radio settingsOnce each time the master starts, read the TAP's channel and the signal level it admits optimizers at, as the CCA does when it brings a TAP up. Shown on the Devices page. Reads only (experimental)
    Bridge addresshost:port of an ESP32 running stream_server, or an RS485-to-Ethernet converter in TCP server mode

    Another device reconfigured the TAP—

      No master here sends these frames, so another device on the bus did: most likely a CCA. A CCA rewrites the TAP's network ID and key, and can change its channel or reflash it; the optimizers then drop off. Unplug it, check every panel is reporting, then clear this.
